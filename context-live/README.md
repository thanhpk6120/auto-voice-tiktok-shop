# Thư mục Context-Live (Sản phẩm Giỏ hàng Live)

Thư mục này được ứng dụng Auto Voice TikTok Shop tự động lưu trữ thông tin các sản phẩm được quét trực tiếp từ phiên livestream (`https://shop.tiktok.com/streamer/live/product/dashboard`).

Các file được lưu dưới định dạng:
`sp-01-ten-san-pham.md`, `sp-02-ten-san-pham.md`...
Hệ thống AI sẽ tự động đọc các file này để:
1. Nhận diện chính xác số thứ tự sản phẩm trên live (Mã 1, Sản phẩm số 2, Áo số 3...).
2. Cập nhật giá bán ưu đãi thực tế và trạng thái ghim giới thiệu.
3. Tư vấn bán hàng và hướng dẫn khách đặt hàng vào giỏ hàng góc trái màn hình.
